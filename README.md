## 🇪🇸 Español

**Arteum** es una aplicación Android para explorar obras de arte del Art Institute of Chicago, construida con Kotlin y Jetpack Compose.
Navega por la colección, busca por título, consulta todos los detalles de cada obra y guarda tus favoritas.

### **Características Principales**
* Exploración de la colección del [Art Institute of Chicago](https://www.artic.edu/) mediante su API pública.
* Búsqueda en tiempo real por título de obra.
* Vista de detalle con artista, fecha, origen, técnica y descripción.
* Guardado y gestión de obras favoritas en local con Room.
* Alternar entre vista en Lista y vista en Cuadrícula.
* Soporte de modo oscuro.

### **Tecnologías Usadas**
* **Lenguaje:** Kotlin
* **UI:** Jetpack Compose + Material 3
* **Arquitectura:** MVVM + Clean Architecture
* **Gestión de estado:** StateFlow + collectAsState
* **Navegación:** Navigation3 con rutas type-safe
* **Red:** Retrofit + Gson
* **Carga de imágenes:** Coil
* **Almacenamiento local:** Room
* **Preferencias:** SharedPreferences

### **Cómo Empezar**
1. Clona el repositorio
```bash
git clone https://github.com/noagomigar/Arteum.git
```
2. Abre el proyecto en Android Studio Hedgehog o superior.
3. Ejecuta en un emulador o dispositivo físico (Android 8.0+).

No se necesita ninguna API key ni configuración adicional — la API del Art Institute of Chicago es completamente pública.

## 🇬🇧 English

**Arteum** is an Android app for exploring artworks from the Art Institute of Chicago, built with Kotlin and Jetpack Compose.
Browse the collection, search by title, view full details of each piece, and save your favourites.

### **Main Features**
* Browse the [Art Institute of Chicago](https://www.artic.edu/) collection via its public API.
* Real-time search by artwork title.
* Detail view with artist, date, origin, medium and description.
* Save and manage favourite artworks locally with Room.
* Toggle between List and Grid display modes.
* Dark mode support.

### **Tech Stack**
* **Language:** Kotlin
* **UI:** Jetpack Compose + Material 3
* **Architecture:** MVVM + Clean Architecture
* **State management:** StateFlow + collectAsState
* **Navigation:** Navigation3 with type-safe routes
* **Networking:** Retrofit + Gson
* **Image loading:** Coil
* **Local storage:** Room
* **Preferences:** SharedPreferences

### **Getting Started**
1. Clone the repository
```bash
git clone https://github.com/noagomigar/Arteum.git
```
2. Open the project in Android Studio Hedgehog or later.
3. Run on an emulator or physical device (Android 8.0+).

No API keys or extra configuration needed — the Art Institute of Chicago API is fully public.
